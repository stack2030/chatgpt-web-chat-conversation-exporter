# Changelog

All notable public changes to this project will be documented here.

This project follows simple semantic versioning while it is early-stage:

```text
MAJOR.MINOR.PATCH
```

## v0.1.0 - 2026-07-06

### Added

- Initial public baseline.
- ChatGPT web conversation export to Markdown.
- Browser-console execution.
- Local-only export flow.
- Same-origin ChatGPT conversation extraction when available.
- DOM fallback extraction when same-origin extraction is unavailable.
- Progress overlay with User / ChatGPT / Total counts.
- Markdown download.
- Independent project disclaimer.
- MIT license.

### Current status

```text
Status: Working as of 2026-07
Target: ChatGPT web
Output: Markdown
Mode: Browser console script
```

### Current scope

- ChatGPT web conversation export.
- Local browser-console execution.
- Markdown output.
- No backend, no analytics, no third-party upload.
- No Google Docs, Notion, Gmail, OAuth, extension APIs, or remote conversion services.

### Not included yet

- Plain text export.
- Timestamped filenames.
- Generated file/artifact export.
- Chrome extension.
- Cloud integrations.

### Notes

ChatGPT is a changing web application. If the UI changes and export breaks, open an issue using the issue template.
